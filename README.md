# House Price Prediction

A full-stack machine learning application that predicts house prices based on property features.

# Project Overview

This project uses Machine Learning to predict house prices based on different property characteristics such as location, area, number of bathrooms, balconies, floor number, parking, furnishing, transaction type, ownership, facing, overlooking, and society.

The project includes:

- Data preprocessing and feature engineering
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Random Forest Regression
- FastAPI backend
- React frontend
- REST API for house price prediction
